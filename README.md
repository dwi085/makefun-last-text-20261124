A Node 22 program that writes the last text message a phone sends at one percent battery — one line, under 200 characters, in the voice of the dying phone itself — to `/output/entry.txt`. Deterministic: two runs produce byte-identical output. No network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
